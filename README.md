# ZhangYvJing Blog

Visit the blog at [zhangyvjing.com/blog](https://zhangyvjing.com/blog/).

文章位于 `src/content/blog/`。首次运行 `npm ci`，使用 `npm run dev` 本地预览，发布前运行 `npm run build`。

提交并推送到 `main` 后，GitHub Actions 自动构建并发布到 GitHub Pages，无需手动上传 HTML。

完整编辑、预览和手动推送步骤见 [blog-workflow skill](.agents/skills/blog-workflow/SKILL.md)。
